# Gepremtek Services Nigeria Limited Website

A professional, responsive full-stack company website for Gepremtek Services Nigeria Limited.

## Included

- Responsive public website for mobile, tablet and desktop
- Gepremtek logo from the supplied artwork
- Services section
- Projects section
- About / company profile section
- Contact and quote request form
- WhatsApp call-to-action
- Express backend API
- Persistent enquiry storage in `data/inquiries.json`
- Responsive admin dashboard at `/admin`
- Admin login using environment variables
- Render deployment configuration

## Run locally

1. Install Node.js 18+.
2. Run `npm install`.
3. Copy `.env.example` to `.env` and change the admin password and session secret.
4. Run `npm start`.
5. Open `http://localhost:10000`.
6. Admin dashboard: `http://localhost:10000/admin`.

## Environment variables

- `PORT` — server port (Render supplies this automatically)
- `ADMIN_EMAIL` — admin login email
- `ADMIN_PASSWORD` — admin login password
- `SESSION_SECRET` — long random secret used to sign admin sessions

## Render deployment

Create a new Web Service from this project.

- Build command: `npm install`
- Start command: `npm start`
- Runtime: Node

Set `ADMIN_EMAIL` and `ADMIN_PASSWORD` in Render environment variables. `SESSION_SECRET` can be generated by Render using the included `render.yaml`.

### Important production note

The starter version stores enquiries in a JSON file. For a multi-user production deployment where data must survive every redeploy and scale across multiple instances, replace the JSON store with PostgreSQL (or another managed database). The API structure is already separated so that migration can be done cleanly.
